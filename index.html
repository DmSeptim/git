Как создать аккаунт на github и репозиторий

  1. Перейдите по ссылке
  2. Выберите пункт: Sign up
  3. Имеется 2 способа регистрации:
    • через электронную почту
    • заполнить форму на сайте
  4. Открыть навигационное меню в верхнем правом углу
  5. Выбрать repositories
  6. В открывшемся окне нажать на зеленую кнопку new
  7. В открывшемся окне пишем название репозитория
  8. Добавляем в разделе "Configuration" Add README переключением тумблера
  9. Создаем репозиторий нажатием кнопки "Create repository"

Как разместить сайт на github

  1. Выберите или создайте репозиторий
  2. Создайте или загрузите файлы. Обязательно главный файл html должен быть назван "index.html"
  3. Перейдите в веръхнем меню в раздел "Settings"
  4. В левом меню выберите "Pages"
  5. В блоке Build and deployment в выпадающем меню Branch выберите ветку main (или master) и нажмите кнопку Save
  6. Подождите несколько минут и в блоке GitHub Pages появится ссылка на ваш опубликованный сайт
